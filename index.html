Você foi contratado como estudante de desenvolvimento web para analisar um pequeno sistema de uma empresa.

Durante a atividade você deverá:

2. Estudo de caso — Empresa Web Fácil

A empresa Web Fácil possui uma página destinada aos seus clientes. A página apresenta informações sobre produtos e serviços, porém atualmente funciona praticamente como uma página estática.

O gerente percebeu que os usuários estão tendo dificuldades para interagir com o sistema.

Entre os problemas identificados estão:

  • O botão "Consultar" não apresenta nenhuma resposta;
  • O sistema não informa o nome do usuário;
  • Não existe cálculo automático de valores;
  • O usuário pode deixar campos obrigatórios vazios;
  • Não existe mensagem quando uma ação é realizada;
  • Os produtos não possuem interação;
  • A página precisa responder aos cliques do usuário.

A direção solicitou que você analise o problema e indique onde o JavaScript poderia ser utilizado.
